# 🚀 Byteroar Task Manager

A full-stack task manager application with a modern landing page and backend API setup.

---

## 📌 Features

* ✨ Responsive Landing Page (Hero, Features, Navbar, Footer)
* 📄 Structured Pages (Landing Page)
* 🔧 Backend API setup using Node.js & Express
* 🧹 Clean project structure
* 🚫 node_modules excluded using .gitignore

---

## 🛠️ Tech Stack

### Frontend

* React.js
* CSS

### Backend

* Node.js
* Express.js

## ⚙️ Installation & Setup

### 1️⃣ Clone the repo

```
git clone https://github.com/asp0766/Byteroar_taskmanager.git
cd Byteroar_taskmanager
```

---

### 2️⃣ Install dependencies

#### Frontend

```
cd task-manager
npm install
npm start
```

#### Backend

```
cd server
npm install
node server.js
```
